# and exporter packages track the core api/sdk release cadence but don't
# always share the same version number scheme (api/sdk use 1.x, some
# instrumentation packages use 0.xxb0) -- with no network access in this
# sandbox to actually run `pip install` and confirm an exact-pin
# combination resolves, a range lets pip's resolver pick a mutually
# compatible set rather than risk a hard failure on a specific
# cross-package pairing that was never installed and verified here.
